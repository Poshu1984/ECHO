# Echo Studio 市場成熟度路線圖（ROADMAP）

> 目標：可接受市場考驗、付費客戶願意接受的成熟度。每日開發依這份清單挑「價值最高、AI 可自行決定」的一項完整成果。

> 最後更新：2026-11-26（claude/daily-20261126-quality-baseline）

## 現況快照（2026-11-26 盤點）

- 成人向功能已相當多：對話（含語音）、繪本式閱讀＋karaoke、短文、翻譯查詢、單字／例句／情境／考試練習、收藏、週分數、六位 Google TTS 家教、XP 解鎖。
- 學習語言 6 種（英日法韓西中），**俄文尚無**；**兒童版尚未開始**。
- 後端是 Express，使用者資料存在 JSON 檔；TTS 與模型金鑰只在後端；有月用量上限。
- 今天以前**沒有 CI、沒有 lint、沒有 API 測試**。
