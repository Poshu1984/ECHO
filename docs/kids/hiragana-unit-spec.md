# 兒童版殼層＋日文平假名單元 規格（v1，2026-11-27）

## 1. 目標

讓 3–12 歲孩子在家長的帳號下，用「看圖、聽聲音、點大按鈕」學會 46 個基本平假名（清音），並讓家長一眼看到孩子學到哪裡。這是 ECHO 兒童版的第一個完整單元。

## 2. 使用情境

| # | 情境 | 期望 |
|---|------|------|
| S1 | 家長登入後，在導覽列點「兒童版」 | 全螢幕進入兒童版：單色背景、日文夥伴 Nami、大按鈕的課程地圖。 |
| S2 | 3–6 歲孩子（還不識字） | 選「小小」模式：題目用聲音和圖示，選項 2 個，答錯不扣分、再聽一次直到答對（無錯誤學習）。 |
| S3 | 7–12 歲孩子 | 選「進階」模式：顯示羅馬拼音與中文發音提示，選項 3 個，測驗會混入前面學過、容易錯的字，並用外形相似的字當干擾選項。 |
| S4 | 一課（一行假名，例如あいうえお） | ① 認識：一次一個大字卡，自動念出聲音、配圖單字；② 聽音找字：聽聲音點出正確的字；③ 小測驗：得到 1–3 顆星。 |
| S5 | 小測驗答對 ≥ 60%（≥ 2 顆星） | 解鎖下一課；低於 60% 鼓勵再練一次（不扣任何東西）。 |
| S6 | 孩子想亂按離開 | 離開按鈕需「長按 2 秒」（家長閘門），避免孩子誤觸回到成人介面。 |
| S7 | 裝置沒有日文語音 | 地圖上顯示「這台裝置沒有日文語音」提示；聽音題改為「看圖補字」（圖片＋缺一個字的單字），仍可完整學完一課。 |
| S8 | 重新整理、關掉 App 再打開 | 進度（星星、解鎖、每個字的對錯次數）保留在這台裝置。 |

## 3. 課程設計（依語言教學專業步驟）

1. **學習目標**：能辨認 46 個清音平假名的字形並對應讀音（聽→認）；進階模式另能說出羅馬拼音與發音要點。濁音、半濁音、拗音、片假名、手指描字為之後的單元。
2. **順序**：依五十音行序 あ→か→さ→た→な→は→ま→や→ら→わ（わ・を・ん），共 10 課。行序是日本小學與主流假名 App 的標準順序，同一行子音相同、母音循環，最容易建立規律。
3. **每課三步（呈現→引導練習→獨立檢核）**：
   - 認識（Presentation）：字＋聲音＋圖像單字（雙重編碼）。
   - 聽音找字（Guided practice）：立即回饋，答對才往下，答錯重播聲音。
   - 小測驗（Assessment）：只在最後顯示星星；不顯示紅叉，避免挫折。
4. **自適應**：每個字記錄對錯次數，弱點分數 =（錯 + 1）／（對 + 2）。進階模式的小測驗會從已學過的課挑弱點最高的字來複習；干擾選項優先用外形相似的字（ぬ/め、ね/れ/わ、さ/ち、る/ろ、は/ほ、い/り、き/さ、あ/お、こ/に、う/つ）。
5. **例字選擇原則**：日常、具體、可用圖示表示、兒童繪本常見；以平假名書寫的和語為主，避免平常寫成片假名的外來語；る、ん、を沒有適合的字首單字，改用字在中間或字尾的例字並標出位置。
6. **發音解說**：用中文（注音）比較，寫出台灣孩子最常犯的錯，例如 し 是 shi 不是 si、ふ 不咬下唇、ら行舌尖輕彈不捲舌、ん 不能放字首、を 念 o、は／へ 當助詞念 wa／e（之後教）。

## 4. 聲音

- 使用裝置內建的日文語音（Web Speech API），**不呼叫雲端 TTS、不耗額度、不需金鑰、可離線**。
- 優先選「裝置本機」語音（`localService`），只念假名與例字，不送出任何使用者資料。
- 預先錄製的高品質音檔需要使用 TTS 金鑰一次性產生，屬老闆決策（見 PR「需要你決策」）。

## 5. 隱私（兒童）

- 不蒐集姓名、生日、照片、聲音；不送出任何資料到伺服器。
- 只在這台裝置的 localStorage 存：模式（小小／進階）、每課星星、每個字的對錯次數。沒有個人識別資訊。
- 不加入任何第三方服務、分析、廣告或外部連結。

## 6. 邊界條件

| 條件 | 行為 |
|------|------|
| localStorage 不可用（無痕模式、被封鎖） | 照常可玩，進度只留在這次。 |
| 進度資料損壞或版本不符 | 回到初始進度，不報錯。 |
| 進度中出現不存在的課或字 | 忽略。 |
| 最後一課（わ行，只有 3 個字） | 測驗題數 = 該課字數；完成後顯示「全部完成」。 |
| 連續快速點擊 | 作答後鎖住選項直到下一題，不重複計分。 |
| 離開兒童版 | 停止語音。 |
| 系統設定「減少動態效果」 | 關閉彈跳、搖晃動畫。 |
| 手機直向 360–430 px 寬 | 不水平捲動；觸控目標 ≥ 64 px。 |

## 7. 驗收標準

1. 46 個字資料完整：每個字有羅馬拼音、所屬課、例字（含該字）、圖示、中文意思、中文發音提示；10 課、字不重複。（單元測試）
2. 選項必含正確答案、不重複、數量符合模式（小小 2、進階 3）；測驗題數 = 該課字數（≤ 5），進階模式在第 2 課起多 1 題「複習」（挑之前最弱的字）。（單元測試）
3. 星星：100% → 3 顆、≥ 60% → 2 顆、其餘 → 1 顆；≥ 2 顆解鎖下一課；星星只升不降。（單元測試）
4. 進度損壞、localStorage 丟例外時不會壞。（單元測試）
5. 從導覽列進入兒童版 → 完成第一課 → 第二課解鎖 → 長按離開回到成人介面；整個流程沒有 console error。（Playwright）
6. 手機尺寸（390×844）沒有水平捲動、主要按鈕 ≥ 64 px。（Playwright 截圖＋量測）
7. 不改既有成人版功能、不新增任何網路請求。（測試＋煙霧測試）
